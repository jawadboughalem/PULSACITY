# Polices des images de partage

Instances statiques de la charte, au format WOFF, pour les images Open Graph générées par `next/og`
(qui ne lit ni le WOFF2 ni les polices variables) :

- `newsreader-500.woff` : Newsreader 500, taille optique 72 (titres) ;
- `public-sans-400.woff` : Public Sans 400.
