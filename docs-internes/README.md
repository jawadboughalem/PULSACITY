# docs-internes

Décisions, payloads et recette. Rien ici n'est publié.

- `charte.md` — la charte graphique : couleurs, polices, tailles, espacements, rayons, ombres, ton de
  voix. Seule source des valeurs de design. **Pas encore versée.**
- `maquettes/` — un export par écran. Un écran sans maquette n'est pas construit.
- `connectors/<nom>.md` — les payloads réels de chaque connecteur, source de ses fixtures de test.
- `decisions.md` — les décisions techniques prises en construisant le socle.
